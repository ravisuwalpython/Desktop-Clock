# Desktop-Clock
A Pygame desktop clock showing analog/digital time, Gregorian date, Nepali (BS) date, and Nepal Sambat.
Run
  pip install pygame nepali-datetime
  python clock.py
  
Features
Analog clock with smooth hands
Digital time and AM/PM
Gregorian + Nepali (BS) dates
Devanagari rendering (Nirmala UI/Mangal)
